# 4_PowerBI_Cardealer
BI dashboard for monitoring marketing effectiveness and sales performance

__Описание кейса__

Автодилер хочет проанализировать эффективность маркетинговых кампаний в интернете. Для этого он нанял консалтинговую IT-компанию, которая должна помочь ему ответить на следующие вопросы:

- Какие маркетинговые кампании работают лучше всего?
- Какие модели продаются лучше всего через интернет?
- Какова общая выручка и маржа за период и какие из моделей выгоднее продавать через интернет?
В ходе пресейла консультанты договорились с клиентом, что сделают пилотный проект на основании ограниченных данных по двум маркам: BMW и Mercedes. Если результаты пилотного проекта устроят заказчика, то будет заключён полноценный контракт на внедрение проекта, который позволит отслеживать эффективность маркетинга на постоянной основе.

В рамках пилотного проекта мы решили объединить данные из Google Analytics и CRM-системы, чтобы посмотреть, какие кампании приводят не только к заявкам, но и к продажам.

Был внедрён Client ID, который пробрасывается из веб-аналитики в CRM, накоплены данные за несколько месяцев и параллельно созданы коннекторы к Google Analytics и CRM.
