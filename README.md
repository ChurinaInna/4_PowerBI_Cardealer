# 4_PowerBI_Cardealer
BI dashboard for monitoring marketing effectiveness and sales performance

**Описание кейса**

Интерактивный BI-дашборд, разработанный в Power BI, для анализа продаж, маркетинговых кампаний, пользовательской активности и конверсионной воронки автодилера.

Дашборд позволяет отслеживать ключевые бизнес-метрики, выявлять драйверы продаж и анализировать эффективность каналов привлечения клиентов.

**Цели анализа**

- Оценить эффективность рекламных кампаний.
- Определить ключевые источники конверсий.
- Проанализировать продажи по регионам и городам.
- Выявить наиболее конверсионные модели и марки авто.
- Проанализировать пользовательскую активность.
- Найти узкие места в воронке продаж.


**Используемые инструменты**

- Power BI  
- DAX  
- Data Modeling  
- Drill-down аналитика  
- Воронка продаж

## Структура дашборда

### Анализ рекламных кампаний

Анализ эффективности маркетинговых источников:

- Конверсии по кампаниям  
- Количество продаж  
- Рейтинг кампаний  
- Выручка по моделям  

**Инсайты:**
- Лидирующая модель по конверсиям — **e220**.  
- По выручке лидирует бренд **Mercedes**.  
- Основной источник конверсий — **Google**.

---

### Конверсии по городам и устройствам

Отображает:

- Конверсии по городам  
- Распределение по устройствам  
- Браузеры пользователей  
- Динамику конверсий  

**Инсайты:**
- 60% конверсий приходится на mobile.  
- Лидирующий браузер — Chrome.  
- По количеству конверсий лидирует Краснодар.

---

### Анализ клиентской активности

Включает:

- Динамику активов по месяцам  
- Сегментацию по бизнес-направлениям  
- Гистограмму и ленточный график  

**Инсайты:**
- Пик активности наблюдается в Q4.  
- Основной вклад дают корпоративный и розничный сегменты.

---

### Конверсии по моделям, маркам и источникам

Позволяет анализировать:

- Конверсию по моделям авто  
- Сравнение брендов  
- Источники трафика  

**Инсайты:**
- Mercedes — лидер по конверсиям.  
- Модель e220 генерирует наибольший объем лидов.  
- Google — ключевой канал привлечения.

---

### Анализ продаж по регионам

Включает:

- Продажи по регионам и городам  
- Drill-down до устройства  
- Геокарту продаж  

**Инсайты:**
- Лидер по продажам — Краснодарский край.  
- Mobile — основной канал покупки.

---

### Воронка продаж

Этапы:

1. Переход на сайт  
2. Конверсия в лид  
3. Просмотр предложения  
4. Счет  
5. Покупка  

**Метрики:**

- Переходы: 66 162  
- Конверсии: 33 033  
- Покупки: 4 086  
- Итоговая конверсия: **6,2%**

---

## Ключевые выводы

- Основной канал привлечения — Google.  
- Наибольшую конверсию дает модель e220.  
- Mobile генерирует большинство лидов.  
- Основной объем продаж сосредоточен в Краснодаре.  
- Основные потери воронки — между лидом и предложением.
